## Zorr game artwork and data

The following files are derived from the Zorr game client and are included so
the feed can display the same names, rarities, drop rates, and artwork as the
game:

- `public/assets/mob-atlas.png`
- `public/assets/petal-atlas.png`
- `data/catalog.json`

The snapshot provenance is recorded in `data/assets-source.json`: the source
script URL, its SHA-256, the snapshot date, and the font hash. No additional
license is granted for this game material by this repository. Rights remain
with the respective game rights holders. Review the applicable terms before
redistributing these files or deploying this project publicly.
